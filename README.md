# dnd35-character-database
D&amp;D 3.5e character database

## Setup
Node.js and pnpm versions are managed by [mise](https://mise.jdx.dev/) (see `mise.toml`).

```
mise install
pnpm install
```

## Develop
### Start Emulators
```
pnpm emu
```

### Start Webpack devserver
```
pnpm start
```

and access `http://localhost:8080`

### Lint
```
pnpm lint
```

## Deploy
```
pnpm run deploy
```
